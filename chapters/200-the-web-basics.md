# 2. Web Basics [2h]

## Introduction

Before Angular, you need the vocabulary of the web: what a browser does, what HTTP is, what asynchronous code means, and where to look when things go wrong (DevTools).

## Goal

### Theory

By the end of this chapter you should be able to explain:

- How a web page travels from a server to your browser.
- What HTTP, HTTPS, TLS, and status codes are, at a high level.
- What a Promise is and how it differs from a synchronous call.
- What Chrome DevTools can show you (Network, Console, Sources).
