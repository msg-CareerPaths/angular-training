# OPT-4. Component Library Development

> ⚠️ **Deprecated:** this optional module is no longer up to date. Kept for reference.

## Introduction

Extract reusable UI from the Online Shop into a separate library and publish it as its own package.

## Goal

### Theory

By the end of this chapter you should be able to explain:

- What a component library is and when to build one.
- What Storybook does and why teams use it.
- The basics of publishing an Angular library to npm.

### Practice

> Add some of the Online Shop's UI elements to a component library and publish it:
> - Create another folder & project for the library.
> - Move a few components into it.
> - Add Storybook to visualize them.
> - Publish to npm.
> - Consume the published package from the Online Shop.

> Add Storybook stories for each component you move into the library. Stories are themselves a form of visual test.
