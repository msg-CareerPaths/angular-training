# OPT-1. Internationalization

## Introduction

Translating the UI into multiple languages is often an afterthought — until it isn't. Angular ships a first-party i18n story (`@angular/localize`), and the ecosystem has lighter alternatives like `ngx-translate`.

## Goal

### Theory

By the end of this chapter you should be able to explain:

- The difference between Angular's built-in compile-time i18n and runtime libraries like `ngx-translate`.
- How `$localize` template literals and the `i18n` attribute work.
- How to extract and manage translation files.

### Practice

> Translate all labels, headings, titles, and buttons of the Online Shop into English and Romanian.
