# 1. Git Introduction [2h]

## Introduction

Git is how you will manage your codebase on every project from here on. This chapter is a quick primer on the commands and workflows you will use daily. If you have already done it in another training, you can skip it.

## Goal

### Theory

By the end of this chapter you should be able to explain:

- What a Git repository is (local vs remote).
- `clone`, `add`, `commit`, `push`, `pull`, `fetch`, `branch`, `checkout`, `merge`, `rebase`.
- The difference between a feature-branch workflow and a Gitflow workflow.
- What a Pull Request is and why squash-merging and deleting the branch matter.

### Practice

> Nothing in the Online Shop yet. Make sure your repo is set up (see Chapter 0 — Rules) and you can clone, commit, and push.
